# GitHub Actions hızlı kullanım

Repository'ye bütün dosyaları yükleyin.

`Actions` → `Build Android APK` → `Run workflow`

Başarılı işlemden sonra:

`Summary` → `Artifacts` → `VirtualPoGoPlus-V2-debug`

APK dosyasını buradan alın.

Eğer workflow `android.api = 36` veya `android.ndk = 28c` satırlarında araç sürümü uyumsuzluğu verirse, hata logunu paylaşın; Python-for-Android/Buildozer sürümüne göre pinleme yapılabilir.
